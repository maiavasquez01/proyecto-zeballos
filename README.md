# NEXO Q – Gestión & Procesos

Sitio web escolar (EPET 20) sobre gestión de la calidad, procesos de desarrollo y metodologías ágiles.
Hecho con HTML, CSS y JavaScript puro, sin dependencias ni instalación.

**Autoras:** Maia Vásquez y Malena Ortega · **Docente:** Prof. Walter Hidalgo

## Secciones
- **Inicio:** presentación y 4 tarjetas de acceso.
- **Gestión de Calidad**, **Procesos de Desarrollo** (selector de modelos tradicionales: Cascada, Modelo en V, Iterativo e Incremental), **Metodologías ágiles** (Scrum, Kanban, XP con Ampliar/Cerrar), **Recursos y Aprendizaje** (comparador de 6 metodologías y encuesta de preferencias), **Sobre Nosotros** y **Contacto**.

## Cómo verlo
Abrí `index.html` con el navegador (doble clic). No necesita servidor.

## Estructura
```
index.html, calidad.html, procesos.html, metodologias.html,
recursos.html, nosotros.html, contacto.html
css/style.css   estilos (mobile-first) 
js/script.js    menú, selector de modelos, comparador, encuesta
img/            imágenes y diagramas SVG
```

## Publicarlo con GitHub Pages
Settings → Pages → Branch: `main` / carpeta `/ (root)` → Save.
